 # 思科与华为命令对照表

> 你学的是**华为（VRP）**，但有时候要用 **Cisco Packet Tracer（IOS）** 做实验。
> 这份表让你在两套命令之间自由切换。
>
> **核心认知：命令不同，概念 100% 一样。**

---

## 一、先记住 5 个"根本差异"

| # | 差异 | 华为 | 思科 |
|---|---|---|---|
| **1** | **进配置模式** | `system-view` | `enable` → `configure terminal` |
| **2** | **取消/删除配置** | **`undo xxx`** | **`no xxx`** |
| **3** | **看配置** | **`display`** | **`show`** |
| **4** | **保存机制** | `save` 一步到位 | `write` / `copy run start` 两步 |
| **5** | **接口编号层数** | 三层：`0/0/1` | 两层：`0/0` |

**只要记住：`undo↔no`、`display↔show`、`system-view↔configure terminal`，剩下的都能类推。**

---

## 二、视图/模式对照

| 层级 | 华为 VRP | 思科 IOS |
|---|---|---|
| 用户模式 | `<Huawei>` | `Router>` |
| 特权模式 | （无独立层） | `Router#` |
| 全局配置 | `[Huawei]` | `Router(config)#` |
| 接口配置 | `[Huawei-GigabitEthernet0/0/1]` | `Router(config-if)#` |
| **进入方式** | `system-view` | `enable` → `configure terminal` |
| **退回上级** | `quit` | `exit` |
| **直接回顶层** | `return` / `Ctrl+Z` | `end` / `Ctrl+Z` |

## 三、查看类命令

| 操作 | 华为 | 思科 |
|---|---|---|
| 看当前配置 | `display current-configuration` | `show running-config` |

| 看接口状态 | `display interface brief` | `show ip interface brief` |
| 看路由表 | `display ip routing-table` | `show ip route` |
| 看 MAC 地址表 | `display mac-address` | `show mac address-table` |
| 看 ARP 表 | `display arp` | `show arp` |
| 看版本 | `display version` | `show version` |
| 看 VLAN | `display vlan` | `show vlan brief` |
| 看 OSPF 邻居 | `display ospf peer brief` | `show ip ospf neighbor` |

## 四、基础配置

| 操作 | 华为 | 思科 |
|---|---|---|
| 改设备名 | `sysname R1` | `hostname R1` |
| 配接口 IP | `ip address 192.168.1.1 24` | `ip address 192.168.1.1 255.255.255.0` |
| 开接口 | `undo shutdown` | `no shutdown` |
| 关接口 | `shutdown` | `shutdown` |
| 配默认网关（交换机） | `ip route-static 0.0.0.0 0 网关` | `ip default-gateway 网关` |

> ⚠️ **注意掩码**：华为支持 `24` 简写，思科传统上要写全 `255.255.255.0`（新版 IOS 也支持 `/24`，但保险起见写全）。

## 五、VLAN 与交换

| 操作 | 华为 | 思科 |
|---|---|---|
| 创建 VLAN | `vlan 10` | `vlan 10` |
| 端口设为接入 | `port link-type access` | `switchport mode access` |
| 端口划入 VLAN | `port default vlan 10` | `switchport access vlan 10` |
| 端口设为 Trunk | `port link-type trunk` | `switchport mode trunk` |
| Trunk 允许所有 VLAN | `port trunk allow-pass vlan all` | `switchport trunk allowed vlan all` |
| Trunk 允许指定 VLAN | `port trunk allow-pass vlan 10 20` | `switchport trunk allowed vlan 10,20` |
| 修改 PVID | `port trunk pvid vlan 10` | `switchport trunk native vlan 10` |
| **VLAN 网关（三层）** | `interface Vlanif10` | `interface vlan 10` |
| 链路聚合 | `interface Eth-Trunk1` | `interface port-channel 1` |
| 把物理口加入聚合 | `trunkport GigabitEthernet0/0/1` | `channel-group 1 mode active` |

## 六、路由

| 操作 | 华为 | 思科 |
|---|---|---|
| 静态路由 | `ip route-static 192.168.2.0 24 10.0.0.2` | `ip route 192.168.2.0 255.255.255.0 10.0.0.2` |
| 默认路由 | `ip route-static 0.0.0.0 0 10.0.0.2` | `ip route 0.0.0.0 0.0.0.0 10.0.0.2` |
| 浮动静态路由 | 末尾加 `preference 100` | 末尾加 `100`（管理距离） |
| **OSPF 启动** | `ospf 1 router-id 1.1.1.1` | `router ospf 1`<br>`router-id 1.1.1.1` |
| **OSPF 宣告网络** | `area 0`<br>`network 192.168.1.0 0.0.0.255` | `network 192.168.1.0 0.0.0.255 area 0` |
| OSPF 改开销 | 接口下 `ospf cost 10` | 接口下 `ip ospf cost 10` |

> ⚠️ **OSPF 宣告的结构不同**：
> - 华为：先 `area 0` 进区域，再 `network`
> - 思科：`network ... area 0` 写在一行

## 七、ACL

| 操作 | 华为 | 思科 |
|---|---|---|
| **基本/标准 ACL** | `acl 2000` + `rule` | `access-list 10` + `permit/deny` |
| **高级/扩展 ACL** | `acl 3000` + `rule` | `access-list 100` + `permit/deny` |
| 允许某网段 | `rule permit source 192.168.1.0 0.0.0.255` | `access-list 10 permit 192.168.1.0 0.0.0.255` |
| 拒绝某网段 | `rule deny source 192.168.1.0 0.0.0.255` | `access-list 10 deny 192.168.1.0 0.0.0.255` |
| 允许访问 80 端口 | `rule permit tcp source 192.168.1.0 0.0.0.255 destination-port eq 80` | `access-list 100 permit tcp 192.168.1.0 0.0.0.255 any eq 80` |
| **接口应用** | `traffic-filter inbound acl 3000` | `ip access-group 100 in` |
| 查看 ACL | `display acl 3000` | `show access-lists` |

> 💡 **通配符（反掩码）写法一样**：`0.0.0.255` 都表示"前 24 位固定"。

## 八、NAT

| 操作 | 华为 | 思科 |
|---|---|---|
| **Easy IP / 过载** | `nat outbound 2000`（配合 ACL） | `ip nat inside source list 1 interface g0/0 overload` |
| 标记内网口 | （华为不需要） | `ip nat inside` |
| 标记外网口 | （华为不需要） | `ip nat outside` |
| 静态 NAT | `nat static global 公网IP inside 私网IP` | `ip nat inside source static 私网IP 公网IP` |
| 端口映射 | `nat server protocol tcp global current-interface 80 inside 192.168.1.10 80` | `ip nat inside source static tcp 192.168.1.10 80 公网IP 80` |
| 查看 NAT 表 | `display nat session all` | `show ip nat translations` |

> ⚠️ **思科必须在内外网口分别标 `ip nat inside/outside`**，华为不需要（它看的是接口方向）。

## 十二、三个最容易踩的坑

### ① 保存机制完全不同

```
华为：
  配完 → 直接生效在 current-configuration
       → save 写入 saved-configuration
       → 忘了 save，重启就丢

思科：
  配完 → 只在 running-config（内存里）
       → 必须 copy run start 或 write 才持久化
       → 忘了保存，重启就丢（跟华为一样痛）
```

### ② `undo` vs `no` 方向反了会报错

```
删一条静态路由：
  华为：undo ip route-static 192.168.2.0 24 10.0.0.2
  思科：no ip route 192.168.2.0 255.255.255.0 10.0.0.2

删错了会提示"命令不存在"，不是"删除失败"
```

### ③ 接口编号

```
华为：GigabitEthernet 0/0/1   → 槽位号/子卡号/端口号（三层）
思科：GigabitEthernet 0/1     → 模块号/端口号（两层）

在 eNSP 里拖的 AR2220，接口是 GE0/0/0 ~ GE0/0/2
在 Packet Tracer 里拖的 2911，接口是 GE0/0 ~ GE0/2
```

## 十三、怎么快速切换（学习建议）

```
① 概念层：完全通用（OSI、VLAN、OSPF、ACL 原理一样）
② 命令层：先学华为（你要考证），思科靠这份表查
③ 实验层：同一个实验在两边各做一次，做完就真正通了
```

**推荐练习**：拿 `W03 VLAN` 这个实验，在 eNSP（华为）和 Packet Tracer（思科）各做一遍，
把配置过程写在同一份笔记里 —— **这份笔记就是你的"双语词典"**。
