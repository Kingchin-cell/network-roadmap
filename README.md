## 一、这个文件夹解决什么问题

你手上有三样东西，但它们原本是散的：

```
① 老师给的课程大纲（PDF，190+ 次课，从 HCIA 到 HCIE + 三厂商扩展 + 网络自动化）
② 三个免费的 B 站课程（各 200 集左右，质量不错但没人告诉你该怎么用）
③ 你自己（本科在读，目标是网络工程师，要稳定、要长期）
```

**这三样东西合起来缺一份「翻译」**——把老师的每一节课，翻译成"看哪个视频的第几集"。

**这个文件夹就是那份翻译。**

## 四、怎么用这套东西（核心工作流）

```
┌─────────────────────────────────────────────┐
│  第 1 步：打开 07-进度追踪表，找到下一个没勾的项  │
│              ↓                               │
│  第 2 步：去 03X 路线文件，看这一项对应哪几集      │
│              ↓                               │
│  第 3 步：看那几集（长集拆开看，每 30-40 分钟停一次）│
│              ↓                               │
│  第 4 步：关掉视频，自己在 eNSP 里重做一遍         │
│              ↓                               │
│  第 5 步：卡住了 → 问 C宝 / 查 04-注意事项        │
│              ↓                               │
│  第 6 步：做出来了 → 在 07-进度表打勾             │
│              ↓                               │

└─────────────────────────────────────────────┘
```

**这套流程里，唯一的死线是第 4 步：不自己敲一遍，等于没学。**

## 五、学习节奏（不要贪快）

| 阶段 | 对应老师大纲 | 建议时长 | 你的年级 |
|---|---|---|---|
| **第一级** | XCNA（≈HCIA） | 8–10 周 | 大二上 |
| **第二级** | XCNP（≈HCIP） | 4–6 个月 | 大二下 — 大三上 |
| **第三级** | XCIE（≈HCIE） | 3–4 个月 | 大三上 — 大三下 |
| **第四级** | 三厂商扩展 + 自动化 | 按需 | 大三下 — 工作后 |

**总账**：视频约 **81 小时**，含动手约 **200 小时**，按每周 6–8 小时算 ≈ **6–8 个月**（不含 XCNA 已走的部分）。

> 详细时间规划见 [06-时间规划.md](06-时间规划.md)。

## 六、五条铁律

1. **以老师大纲为准。** 三套视频是工具，不是路线——视频里有多余的、也有缺的，按老师大纲的顺序走，不要被视频的目录带着跑。
2. **不自己敲一遍 = 没学。** 每个实验必须关掉视频重做一次。
3. **一次只走一级。** HCIA 没走通，不要点开 BGP 的 23 集。
4. **缺口不可怕，装不知道才可怕。** 免费课确实有覆盖不到的地方（MPLS VPN / QoS / SR），见 05 号文件，别跳过。
5. **每周一次 git commit。** 这是两年后你简历上"我真的坚持了两年"的唯一证据。
